## 🚀 Flagship Engineered Projects

### 🤖 [CHITTI — Cognitive Human Interactive Technological Intelligence](https://github.com/abishek-tr21/CHITTI-Robot) *(2026)*
*Full-Stack AI Robotics & Mechatronics Platform | Capstone Project @ SASTRA University*
- **Software & Cloud Architecture:** Developed the core software architecture using concurrent Python processes for sensory input and acoustic output. Integrated the OpenAI real-time voice API over Wi-Fi to establish a sub-second natural language processing pipeline.
- **Embedded & Computer Vision:** Programmed real-time human face tracking leveraging OpenCV and OpenMV camera modules, processing visual data with **<100ms latency**.
- **Hardware-Software Co-Design:** Implemented robust UART serial communication between a Raspberry Pi 5 central processing unit and Arduino UNO edge actuator modules. Engineered and 3D-printed custom mechanical subsystems, including servo-driven robotic eyes and an analog **5-inch CRT monitor** audio waveform visualizer driven by dual TDA7297 amplifiers.

### 🛰️ Real-Time Flight Computer for Model Scale Rockets *(2025)*
*Embedded Firmware & Telemetry Acquisition System*
- **Firmware Engineering:** Engineered real-time data acquisition firmware on Raspberry Pi Pico (RP2040), reliably processing high-frequency telemetry streams from connected 6-axis MPU6050 (IMU) and BMP280 barometric altitude sensors.
- **Closed-Loop Control:** Designed and implemented a closed-loop Thrust Vector Control (TVC) algorithm to dynamically adjust flight trajectory parameters using servo motors driven by continuous sensor feedback.
- **Logging & Wireless Telemetry:** Developed an onboard SD card data-logging module to serialize telemetry data for post-flight analysis, alongside a companion REST API mobile application for remote wireless monitoring and system configuration.

### 🔬 Early Diagnosis of Autoimmune Skin Conditions via Deep Neural Networks *(2023)*
*Medical Imaging Classification & Data Pipeline Optimization*
- **Deep Learning Model:** Built and trained a convolutional deep neural network tailored for automated diagnostic classification of medical imaging datasets.
- **Data Engineering:** Developed data preprocessing pipelines using Python (NumPy, TensorFlow) to clean, normalize, and augment high-resolution image data.
- **Algorithmic Optimization:** Fine-tuned hyperparameters and optimization algorithms to enhance prediction accuracy, significantly reducing false positive rates while validating computational efficiency for early-stage detection.
